## 关键证据到决策的可追溯性

| 决策 | 支撑事实 | 结论边界 |
|---|---|---|
| Ditto 不进入 MVP | 官方架构明确包含五类服务与 MongoDB；其 Search 不是 PostGIS spatial engine | 不否定 Ditto 的设备 Twin/Policy 能力，只否定本阶段投入产出比 |
| Observation 兼容 SensorThings | 标准的 Observation 具 phenomenonTime、result、Datastream/FOI 语义 | GOWM 加 observer/subject/confidence/correlation/provenance；不是 1:1 OData 实现 |
| PostGIS 是空间事实源 | 官方函数与 GiST/KNN 可直接实现 P0 查询 | H3 是派生索引，不替代精确包含/相交/距离 |
| MQTT 取代高频轮询 | MQTT 5 定义 QoS/session；Mosquitto 是成熟轻量 broker | 仅用于 live delivery；PostgreSQL/SSE 提供历史 replay；业务仍按 eventId 幂等 |
| h3-pg 原生存储 | 官方 API 定义 `h3index`、geometry indexing、parent/children、polygon-to-cells | H3 仍是派生索引；精确安全边界回到 PostGIS geometry |
| MobilityDB 只做 temporal primitive | SequenceSet 可表达断开的定义域；v1.3 core 不含 clock/provenance/uncertainty/negative-evidence model | Observation/TimeSolution/Measurement/coverage/version lineage 必须由 GOWM+/STAS 数据模型补足 |
| 单库优先 | PostGIS 已覆盖关系、JSONB、空间和中等时序；Timescale 是同库扩展 | 数据量/SLO 达到门槛才引入扩展或第二存储 |

## 研究风险

- 版本活跃度会变化；正式上线前必须重新执行 dependency/SBOM/license review。
- OGC SensorThings 2.0 在检索日不能作为稳定兼容基线；只对已发布 1.1/Tasking 1.0/WebSub 1.0 设计映射。
- PoC v1.2 在 digest-pinned MobilityDB image 上安装 h3-pg 4.5.0；目标环境仍需验证组合镜像、extension upgrade、迁移和 DB benchmark。
- MobilityDB 官方预生成文档站在检索日未单列 stable-1.3，且 master 含未发布能力；稳定函数以 v1.3.0 tag SQL/source/tests 为准。
- Redpanda 的可用功能与许可证边界须按部署方式复核，因此即使其运维模型有吸引力，也不是本阶段默认项。
