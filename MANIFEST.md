## Target-host acceptance

```bash
npm ci
npm run acceptance
```

This runs Compose config/build/up, h3-pg migration/type/function checks, seed, PostGIS integration, C1–C9 HTTP/MCP/SSE checks, 1M temporary-table spatial/H3 benchmark, 100/1k/10k events/s offered-load, MQTT QoS 1 loopback, storage growth, subject replay, Docker stats and Mosquitto metrics. It intentionally leaves the stack running for inspection.

## Archive policy

The release ZIP contains source, dependency lock, reports, migrations, tests and measured output. It excludes `node_modules/` and generated `dist/`; both are reproducibly generated by `npm ci && npm run build`. No `.env`, credentials, database volume or runtime secret is included.

Verify project files after extraction:

```bash
sha256sum -c SHA256SUMS
```

Verify the archive with the sidecar file placed next to it:

```bash
sha256sum -c SHA256SUMS
```

## Known acceptance boundary

This package is a working engineering baseline, not a claim of production readiness. Production control is blocked until target-host G1–G10 evidence is all PASS, field-level source/freshness policy is approved, and Stage 1 security/retention/replay soak gates are closed. Full H3 counter reconciliation during database replay remains a documented Stage 1 item.
